# AutoFish — новая базовая версия

Это новый Android Studio проект, созданный с нуля.

## Что уже есть
- Русский главный экран.
- Запрос разрешения «Поверх других приложений».
- Служба специальных возможностей с разрешением на жесты.
- Плавающая панель поверх Roblox.
- Кнопка «Я забросил» для ручной отметки заброса.
- Кнопки сброса и закрытия панели.

## Что пока не реализовано
- Автоматическое распознавание шкалы клёва.
- Автоматическое нажатие/удержание по шкале.
- Автоматическое обнаружение кнопки Roblox.

Не заявляется, что эти функции работают: Roblox может не предоставлять игровые элементы через Accessibility API. Для распознавания изображения понадобится отдельное разрешение на захват экрана (MediaProjection), обработчик кадров и алгоритм обнаружения шкалы.

## Сборка
Открой папку проекта в Android Studio (Giraffe или новее), дождись Gradle Sync и собери:
Build → Build Bundle(s) / APK(s) → Build APK(s).

Минимальная версия Android: 8.0 (API 26).
